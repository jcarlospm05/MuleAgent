# MuleAgent Administrador

Flutter 3.47.9 · Android API 24+ · `com.muleagent.administrador`.

```sh
flutter pub get
flutter analyze
flutter test --timeout=120s
flutter build apk --debug
```

Reutiliza el flujo de captura del paquete local `operador` y su codec `mule_data`. `admin_data` agrega recepción inmutable, versiones, cruces y auditoría. La aplicación tiene su propio almacenamiento SQLCipher y su propia identidad de instalación.

[Guía funcional y límites](../../docs/administrador-v1.0.md).
